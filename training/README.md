The IPython notebook contains the full workflow
needed to create the model that is used for inference.
Data used for training needs to be downloaded
separately from
[Kaggle](https://www.kaggle.com/datasets/subirbiswas19/skin-disease-dataset).

The Notebook has been tested on Google Colab.
Modifications maybe needed for other environments
which support IPython notebooks.

Portions of the notebook contain code from:
[Sipeed TinyMaix repsitory](https://github.com/sipeed/TinyMaix)

available under the Apache 2.0 license.
